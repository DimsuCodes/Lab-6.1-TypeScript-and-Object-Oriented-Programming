## Reflection

   # Inventory Tracker

   A TypeScript lab using classes, inheritance, and polymorphism to track
   physical and digital products and calculate tax.

   ## How to Run

```
   npm install
   npx tsc
   node dist/main.js
```

This lab was challenging for me. I completed it with step-by-step help
(including from an AI tutor), and I don't feel fully confident with the
concepts yet.

**What I understand better now:**
- Lowercase `string` / `number` are the types to use
- A subclass uses `extends` and `super()` to reuse the parent's properties
- Overriding lets each product calculate tax its own way

**What I still find confusing:**
- When to use a getter vs. a regular method
- Access modifiers (`public`, `private`, `protected`)

**Next step:** I'd like to review classes and inheritance again, and
rebuild a similar small project on my own.
